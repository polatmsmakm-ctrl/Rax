# RaX

تويكات أصلية لتطبيق X (تويتر) 12.8 — كود مكتوب من الصفر، مبني على فهم بنية التطبيق نفسه، مو نسخ من BHTwitter أو أي تويك موجود.

## الوحدات
- **RaXFix** — يصلح مشكلة الجلسة/الـkeychain عند السايدلود (نفس فكرة IGFix بالإنستغرام).
- **RaXAds** — يقلّل وحدات إعلانية منفصلة وواضحة: إعلانات Google المضمّنة بالبحث/الاستكشاف، تخطي إعلانات الفيديو تلقائياً، إخفاء بانر «روّج لهذا المنشور»، وإخفاء شارة Promoted (تجميلي فقط).

**ما تقدر الوحدات هذي تسويه:** التغريدات المموّلة اللي تدخل ضمن القائمة الرئيسية نفسها تجي من السيرفر مباشرة ومدموجة بالخط الزمني العادي — مافي هوك ثابت وموثوق يوقفها من جهة التطبيق، فهذا خارج النطاق حالياً.

## البناء
GitHub Actions يبني الدايلبات تلقائياً عند كل push على `main` ويحطها في `dist/`.

من تطوير وإعداد راشد الشمِّري.
